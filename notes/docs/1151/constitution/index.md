# 課程筆記｜憲法專題研究（大學部）

115 學年度第 1 學期，星期一第 7、8 節，2 學分、選修，科目代碼 BLW52401。本學期以權力分立
原則為核心，前 3 週講權力分立的理論與政府體制典範，其餘各週逐案解析大法官有關憲法結構的
指標解釋，最末一週期末開書考試。
