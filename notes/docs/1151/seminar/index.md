# 研討會筆記｜憲法專題研究（一）

115 學年度第 1 學期，法碩一，星期一第 3、4 節。本學期的專題是違憲審查制度的正當性
（legitimacy of judicial constitutional review），課程內容分五段：導論的辯論概況、Bickel 原典
與 Kelsen 及 Schmitt 關於憲法守護者的辯論、批判意見、分從政治理論與民主理論與對話理論與機構
理論展開的擁護意見，以及末段的省思。
