# 課堂逐字稿：編註起草交辦

給編註 agent 讀的工作說明。主對話派工時指定週次目錄與 cue 範圍。產物是一張表，`Skripte/gen_tex.py` 依表在正文該詞之後加腳註，`--md-out` 另印成站上頁面的 footnote。體例取自 Translation 倉 `RenwenLaifeng/Notizen/編註交辦.md`，判準改成法學課堂用。

## 判準

一個認真讀這門課、但沒有聽過這堂課的法律系研究生，缺了這條註還讀不讀得懂；讀不懂就加。本週全稿每個對象只在首見處註一次。

逐類都要註（站主 2026-11-24「編註做好做滿」）：

- 裁判與解釋：釋字、憲判字、外國判決。寫全稱、作成日期、與課堂所述相關的那一點（解釋文或主文、理由某段），以原文為據，引號內逐字。
- 法條：寫法規全稱、條項與該條規定的內容；條文以現行版本為準，課堂所說是舊條文時另寫版本。
- 人物：全名、生卒年（在世者不寫生年以外的推測）、與課程相關的身分（大法官任期、任職、代表著作）。學生、助教不註。
- 文獻：書名、篇名首見處寫作者、刊名或出版者、年份；課綱指定文獻寫第幾週。
- 機關與制度：課堂提到而沒有解釋的（速記錄制度、大法官會議、法國第五共和憲法委員會、divided government）。
- 外語詞：原文、語種與意思；英文法學術語附中文通行譯名。
- 時事：課堂提到的近期事件（大罷免、行政院不副署、Gulf of America 改名）寫日期與經過一句，出處用機關公告或主要媒體。

不註：講者原話已解釋清楚的；一般常識；校訂待核表（`Notizen/<週>/chunk*.uncertain.tsv`）裡尚未核定的詞；評價、講者觀點的延伸。講者說錯的事實（年份、數字、人名對而事不對），正文照錄，註裡寫正確的事實與出處，不寫「講者有誤」。

## 出處

每條都要有出處，查不到就不寫。優先順序：

1. 本機：判決與解釋全文 `~/Documents/NTU/1142/phenom-court-data/data/processed/constitutionalCourt-reasoning-fulltext.json`（大檔，以 python 依字號取）、`constitutional-court-app.json`（字號、日期、主筆、主文）、`justices.json`（大法官任期）；課程材料 `1151/seminar/syllabus.md`、`readings/index.md`、`library/text/`；核對紀錄 `1151/seminar/asr/<週>/核對紀錄.md`。
2. 官方網頁：憲法法庭 cons.judicial.gov.tw、全國法規資料庫 law.moj.gov.tw、立法院、總統府。
3. 學術書目：國家圖書館、出版者頁面。維基百科只當線索，註文裡的年份須有第二來源。

出處欄寫網址或本機路徑（相對於倉根 `SCU_Constitutional_Law_Tang/` 或絕對路徑），多項以「 ; 」分隔。WebFetch 回傳的是摘要，逐字引文要以 curl 存檔或本機全文核對。

課程問答集已有書目 `1151/seminar/課程問答/refs.bib`：條目已在其中者（`chen2011`、`ccj113-9`、`ccj114-1`、`garvey2004`、`bickel2004`、`kramer2001gaf` 等，開檔看鍵），在「引」欄填鍵，要頁碼或段號時寫成 `鍵|頁碼`，腳註會印出完整書目。

## 註文寫法

一到三句，只寫事實，句子成分完整。不寫「本堂」「老師提到」「此處指」這類提示語，直接寫那個東西是什麼。法律用語用規範動詞（規定、明定、宣告、適用），機關寫全稱（中華民國司法院大法官、中華民國憲法法庭）。條號寫「第 30 條第 2 項」。中文與半形數字、拉丁字母之間留一個半形空格。註文不得含 `{ } \ % # $ & _`。

註文會印在書上、放上網站，是給讀者看的正文：落筆前讀 `~/.claude/skills/去除AI味.md` 最前面的落筆守則；表寫完後把註文欄抽成一份 scratchpad 草稿，跑 `/usr/bin/python3 ~/.claude/hooks/prose-selfcheck.py <草稿檔>`，機器掃描不報錯、人工清單逐條讀過，才寫進表。

## 材料

路徑相對於 `1151/seminar/逐字稿/`：

- 正文：`Notizen/<週>/reviewed.tsv`（cue、start、end、text；校訂後的文字，只讀）。表的 cue 欄即此表的 cue；詞照此表逐字抄，不含書名號。
- 小節與段落：`Teile/<週>.tex`（產生器產物，只讀，可看小節標題找上下文）。
- 該週課堂整理：`../課程問答/Teile/<週>_notes.tex`，其中已核定的出處照用。

## 輸出

`Notizen/<週>/編註_<代號>.tsv`（代號由派工時指定），你是唯一寫入者。五欄：`cue`、`詞`、`註`、`出處`、`引`。表頭照寫這五個欄名。

## 驗收

交出前把你的表暫時複製成 `Notizen/<週>/編註.tsv`，跑 `python3 Skripte/check_notes.py <週>` 回 0，再刪掉那份複製（主對話合併時會重建）。
