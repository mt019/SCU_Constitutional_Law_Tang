# 湯德宗老師東吳憲法課程資料

東吳大學法律學系湯德宗老師開設的憲法課程，本倉按學期收其材料與我的筆記。目前收的有 114 學年度
第 2 學期（1142）的「憲法專題研究（四）」與大學部「憲法案例解析（法二 B）」，以及 115 學年度
第 1 學期（1151）的「憲法專題研究（一）」與大學部的「憲法專題研究」。湯老師在國立臺灣大學開設的課我旁聽過，筆記收在 `notes/docs/1142/ntu/`。

指定書、裁判與大法官講堂講義跨學期共用，放在根層；課綱、每週閱讀、我的產出、同學的材料綁學期
與課，放在 `<學期>/<課>/` 底下。

## 目錄

- `library/books/`：五本指定書與一篇指定期刊論文，檔名體例為「作者_書名_版_年」。
- `library/text/`：各書抽出的文字層，一本一夾（`alexander`、`barber_fleming`、`beatty`、`gaf`）。
- `library/湯德宗_著述與大法官案件清單.md`：湯老師的著述與其參與之大法官案件。
- `cases/court/00_釋字/`：司法院大法官解釋 31 件的官方頁面與判決文字層；釋字第 738 號、第 769 號
  另收公開之卷內文書。
- `cases/court/01_憲判/`：憲法法庭判決 4 件；111 年憲判字第 6 號收公開之卷內文書 43 件。
- `cases/statutes/`：中華民國憲法、憲法增修條文、中央法規標準法、地方制度法、立法院職權行使法、
  中華民國刑法、憲法訴訟法，與德國基本法（GG）。
- `ocw/`：大法官講堂「中華民國憲法及政府」講義 114 份。
- `1142/seminar/`：憲法專題研究（四）。`syllabus.md` 是授課計劃表，`readings/` 收各週指定閱讀與
  案例材料，`my/` 收我認領的導讀題目（釋字第 738 號、第 769 號、111 年憲判字第 6 號、德國墮胎
  判決）與書面報告，`peers/` 收同學的導讀與期末報告。
- `1142/undergrad/`：憲法案例解析（法二 B），材料在 `notes/docs/1142/undergrad/`。
- `1151/seminar/`：憲法專題研究（一），主題為違憲審查正當性。`readings/index.md` 登記各週文獻
  的出處與本機取得狀況。
- `1151/constitution/`：大學部憲法專題研究（BLW52401，2 學分選修），主題為權力分立原則。
  `syllabus.md` 是授課計劃表，`asr/` 收課堂錄音的逐字稿。
- `notes/`：mkdocs 筆記站，`docs/` 內同樣按 `<學期>/<課>/` 分。
- `latex/`：引句卡的 `.tex` 與輸出，以及字型 pack 的 manifest 與安裝腳本。字型檔本身在
  `~/Documents/NTU/1142/font-lab/packs/scu-constitutional/`，不隨本倉進版控。
- `scripts/`：PDF 與 EPUB 的文字層抽取腳本。
- `notebooks/`：Jupyter notebook，`deploy.yml` 會把它同步進筆記站。
